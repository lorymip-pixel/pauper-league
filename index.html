Backup e trasferimento

Esporta tutti i dati in JSON per conservarli o trasferirli su un altro dispositivo. Importando un backup, i dati correnti vengono sostituiti.

I dati della lega sono condivisi tramite Google Sheets. Usa il backup solo se devi conservare o trasferire una copia dei dati.

Gestione dati

Puoi ripristinare il set demo oppure svuotare il database locale.

Modello dati già separato in players, decks e matches, con identificativi stabili. L’interfaccia è collegata a Google Sheets tramite Apps Script e sincronizza i dati tra dispositivi. Proteggi l’endpoint prima di condividere pubblicamente il sito.
